#  Chess Game

A classic two-player chess game with a clean interface and standard rules. Play against a friend locally or challenge an AI opponent (if implemented). Built with [Your Tech Stack, e.g., Python + Pygame / JavaScript + React / Java Swing].



##  Features

- Full standard chess rules 
- Two-player local mode
- Move validation & check/checkmate detection
- Clean visual board with piece icons
- Move history and turn indicator

##  How to Play

1. Clone the repository
2. Install dependencies
3. Run the game
4. White moves first. Click/tap a piece, then click a highlighted square to move.
5. The game ends when a player is checkmated or resigns.
